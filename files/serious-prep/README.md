# Serious Prep — 30 Day Full-Stack Interview Plan

> A focused, day-by-day plan that touches **all 10 pillars** every single day: Angular, Node.js, Spring Boot (with Hibernate), MongoDB, PostgreSQL, High-Level Design, Low-Level Design, DSA, Design Pattern, and DevOps.

Each day file is **self-contained study mode**: enough content to study from cold without jumping anywhere, plus deep-dive links to the topic files in the sibling folders for when you want to go further.

---

## How to use this folder

1. **One day per day.** Allocate ~2.5–3 hours. Each pillar gets roughly 15–25 minutes.
2. **Read first, then code.** Each section ends with a small drill or interview question — actually answer it out loud or in writing.
3. **Follow the deep-dive links** when something feels shaky. The day file is the "minimum effective dose"; the linked folder file is the "full dose".
4. **Spaced repetition.** Day 30 is a mock-interview wrap. Days ending in 0/5 are lighter, so you can use them to revise the previous block.
5. **Track:** check the boxes at the end of each day file.
